## [1.1.0]
### Added
- Added a JavaScript file (`script.js`) to improve the functionality and interactivity of the website.
- Added a search bar on the Services page to allow users to search for specific beauty services more easily.
- Added dynamic content filtering using JavaScript to display only services that match the user's search input.
- Added client-side form validation on the Contact page to check user input before the form is submitted.
- Added validation for name, phone number and message fields to ensure users enter valid information.
- Added alert messages to inform users when incorrect information has been entered in the contact form.
- Added a lightbox gallery feature that allows users to click on images and view them in a larger format.
- Added HTML5 form elements such as a dropdown menu, date picker and textarea to improve the booking form.
- Added a `robots.txt' file to guide search engines when indexing the website pages.
- Added a `sitemap.xml` file to help search engines understand the structure of the website.
- Added meta descriptions and keywords to improve the website's search engine optimisation (SEO).

### Changed
- Updated the Contact page form to include unique IDs required for JavaScript validation.
- Improved the layout of the Services page to support the new search and filtering functionality.
- Updated the Gallery page to support the lightbox feature for a better user experience.
- Improved website usability by making certain features more interactive and user-friendly.
- Organised JavaScript code into an external file (`script.js`) to improve maintainability and readability.
- Updated form fields to use more suitable input types such as date and telephone inputs.

### Fixed
- Fixed issues with form validation by ensuring that JavaScript correctly targets the required form fields.
- Fixed JavaScript syntax errors caused by missing brackets and incorrect placement of code blocks.
- Fixed service search functionality by assigning appropriate classes to service items.
- Fixed gallery functionality so that images open correctly in the lightbox when clicked.
- Fixed minor coding errors identified during testing of the website features.
- Fixed some usability issues to ensure the website works more smoothly across different pages.


## Semantic Versioning

Format: MAJOR.MINOR.PATCH  
Example: 2.1.3

- MAJOR → Breaking changes (1.0.0 → 2.0.0)  
- MINOR → New features (1.0.0 → 1.1.0)  
- PATCH → Bug fixes / small improvements (1.0.0 → 1.0.1)
